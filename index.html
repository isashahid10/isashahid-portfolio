WHOOP Companion: a WHOOP 4.0 that works without the subscription

A companion app that keeps a WHOOP 4.0 band fully usable without the vendor subscription. It pairs over Bluetooth and computes everything on the phone (recovery, strain, sleep staging, HRV) with no cloud round-trip, so the sensor data never leaves the device. Built in Dart and Flutter on top of OpenStrap, which separates the band's protocol decoder, the metrics layer, and the app itself into distinct pieces.

My fork extends it with resistance-training logging, nutrition tracking, weather context, and AI coaching on top of the raw sensor stream. Complete and in daily use, with updates shipping regularly.

CodeProof

A VS Code extension that records your work as you write it, then proves nobody edited the record afterwards. It snapshots the workspace on an interval, links every snapshot into a SHA-256 chain so any retrospective edit invalidates everything downstream, and stores the whole event log locally in SQLite. Nothing leaves the machine.

On top of that: a replay player that scrubs back through a session like video, a flag analyser that surfaces large pastes and unusual jumps for human review, and exportable PDF reports with Gemini-written narratives of how the work actually progressed. Built for academic integrity cases, where proving when something was written matters as much as what was written.

TypeScript VS Code Extension API SQLite Gemini API SHA-256 chaining

STORMCAST

A cross-platform desktop trading terminal for weather markets. Ask your phone for tomorrow's high and you get one number, but the model actually produced 51. STORMCAST ingests the full ECMWF ensemble for the specific airport stations these markets settle against, builds a calibrated probability distribution instead of a point estimate, and prices it against live market odds.

An Electron and React front end over a Python forecasting engine, with fractional Kelly sizing, paper trading, and calibration analytics that check whether a 70% call actually happens 70% of the time. Four releases shipped with signed macOS, Windows and Linux builds and delta auto-updates. Source is private: it is a commercial product and the strategy is the edge.

TypeScript React Electron Python ECMWF ensemble Kelly sizing
